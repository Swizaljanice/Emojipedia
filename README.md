# Emojipedia

A simple React application that displays a dictionary of emojis with their names and meanings. The project demonstrates the use of components, props, and array mapping in React.

## Overview

**Emojipedia** is a React app that maps over an array of emoji objects to create and display a structured list of emoji entries. Each entry shows the emoji symbol, its name, and its meaning. 

---

## Features

- **Dynamic Rendering**: Uses the `map()` function to dynamically create emoji entries from an array.
- **Reusable Components**: Utilizes reusable React components for a clean and maintainable code structure.
- **Styled Layout**: Includes CSS styling for a visually appealing user interface.

---

## Technologies Used

- **React**: For building the user interface.
- **JavaScript (ES6)**: Core language features such as arrow functions and array mapping.
- **CSS**: For styling the app.
